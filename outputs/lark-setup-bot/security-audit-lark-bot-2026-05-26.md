## 🔍 Audit findings chi tiết

### Finding 1 — Scope `mail:user_mailbox.message:send` quá rộng

**Severity:** 🟡 Medium

Bot hiện có scope cho phép gửi mail **từ TẤT CẢ user inbox** mà bot có OAuth. Đúng nguyên tắc least-privilege là chỉ nên có scope cho mailgroup `tuyendung@seongon.com`.

**Why it matters:** Nếu refresh token của HRM bị lộ, attacker có thể gửi mail mạo danh BẤT KỲ user nào đã authorize bot, không chỉ tuyendung@.

**Action:**
```
Lark Developer Console → HR SEONGON Bot → Permissions
→ Thay scope mail:user_mailbox.message:send
→ Bằng scope hẹp hơn: mail:mailgroup.message:send (nếu Lark hỗ trợ)
→ Hoặc tạo bot riêng cho tuyendung@ với chỉ scope cần thiết
```

### Finding 2 — Refresh token rotation chưa có cảnh báo expire

**Severity:** 🟢 Low

Script `code/refresh_lark_token.py` chạy mỗi 90 phút để rotate user access token (TTL 2h). Tuy nhiên KHÔNG có alert khi refresh token chính (TTL 30 ngày) sắp hết.

**Why it matters:** Khi refresh token hết, scheduler agent (interview_invite, rejection_mail) sẽ fail im lặng → không gửi được mail PV cho ứng viên.

**Action:**
```python
# Trong code/refresh_lark_token.py, thêm:
expires_in_days = (datetime.fromisoformat(refresh_expires_at) - datetime.now()).days
if expires_in_days < 7:
    send_lark_im_alert(f"⚠️ Refresh token expires in {expires_in_days} days, please re-OAuth")
```

### Finding 3 — Bot không log các action sensitive

**Severity:** 🟡 Medium

Khi bot gửi 1 email mời PV hoặc tạo Lark Calendar event, **chưa có log** ai trigger + payload gì. Chỉ có file `outputs/agent-run-log.txt` ghi kết quả high-level.

**Why it matters:** Khi cần audit "ai gửi mail này", "tại sao ứng viên A nhận mail từ chối lúc 02:00 sáng" → không trace được.

**Action:**
```python
# code/lark_mail.py:
import logging
audit_logger = logging.getLogger("lark-audit")
audit_logger.addHandler(FileHandler("logs/lark-audit.log"))

def send_mail(recipient, template, sender_id):
    audit_logger.info(f"send_mail | recipient={recipient} | template={template} | sender={sender_id} | ts={now}")
    # ... existing send logic
```
